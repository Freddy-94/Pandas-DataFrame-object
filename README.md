# Pandas-DataFrame-object

1. READ/INSPECT DATA
2. SELECT SUBSETS OF DATA
3. FILTER DATA BY A BOOLEAN EXPRESSION / BY NULL VALUES
4. SORT DATA
5. GROUP DATA
6. REARRANGE DATA
7. RANK DATA
8. PLOT DATA
